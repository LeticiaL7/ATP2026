## Resumo
O objetivo era criar uma aplicação em Python com um menu que permite criar listas de números inteiros, gerar uma lista aleatória ou introduzir os números que pretender. Além disso, depois pode realizar operações como a soma, média, procurar o maior e menor números, verificar se a lista está ordenada e ainda, procurar elementos. Até ser escolhida a opção "Sair (0)", o programa continua a executar, mostrando no final, a última lista guardada.
